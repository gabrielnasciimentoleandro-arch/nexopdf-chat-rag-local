# Guia rápido de entrega na DIO

## Nome sugerido do repositório

`nexopdf-chat-rag-local`

## Descrição sugerida no GitHub

Chat local com PDFs usando busca vetorial, RAG, fontes rastreáveis, Streamlit e integração opcional com Ollama.

## Publicação

1. Crie um repositório público e vazio no GitHub.
2. Na pasta deste projeto, execute:

```bash
git init
git add .
git commit -m "feat: adiciona chatbot local baseado em documentos"
git branch -M main
git remote add origin https://github.com/gabrielnasciimentoleandro-arch/nexopdf-chat-rag-local.git
git push -u origin main
```

3. Abra o repositório no GitHub e confirme se as duas imagens do README aparecem.
4. Na plataforma DIO, clique em **Entregar projeto** e cole a URL pública do repositório.

## Antes de enviar

- confirme se a URL do repositório está correta no README;
- confirme se o perfil indicado na seção de autoria está correto;
- não publique documentos pessoais, credenciais ou arquivos confidenciais;
- mantenha as pastas `inputs`, `assets/screenshots`, `src` e `tests` no repositório.
